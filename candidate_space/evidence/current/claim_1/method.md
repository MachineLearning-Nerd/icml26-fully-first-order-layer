# Claim 1 method

Eight seeded strongly convex QPs are generated by construction with known strict active sets. An exhaustive active-set solver independently obtains each lower solution. The exact reference differentiates the KKT system. The Algorithm 1 path instead solves the base and objective-perturbed QPs and uses their finite difference.

The verifier counts lower solves and exact-sensitivity calls. Its negative control deliberately invokes the forbidden exact-sensitivity routine and must exit nonzero.

The first failed calibration used an unnormalized absolute cutoff. The frozen
contract instead uses relative error, adds a fourth finite-difference decade,
and requires the final decade to contract by at least a factor of five.

Command: `uv run --frozen python -m reproduction.run`
